========================
Bundle common accounting
========================

Install at once all common modules related to the accounting.

IMPORTANT: Before installing
============================

.. warning::

   **Double-check both requirements before installing this module:**

   * Make sure ``l10n_es``, ``l10n_es_partner`` and ``l10n_es_toponyms``
     **are already installed**.
   * Make sure the **chart of accounts is configured**.

Description
===========

This module has as dependencies all common modules related to the accounting.
Thus, it allows install at once all those modules.
