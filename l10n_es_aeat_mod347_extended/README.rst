========================
AEAT modelo 347 extended
========================

Description
===========

According to https://www.boe.es/buscar/doc.php?id=BOE-A-2025-25390, Article 1,
the number of convocation BDNS for the AEAT model 347 is 6.

This extension adds a check to ensure that if the operation key is "E" and a
BDNS number is provided, it must be exactly 6 digits long.
