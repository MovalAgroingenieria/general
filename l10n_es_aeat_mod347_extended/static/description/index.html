l10n_es_aeat_mod347_extended

Extension module for AEAT Model 347 (Odoo 10.0)

This module extends the standard Spanish AEAT Model 347 export configuration for Odoo 10.0.

It is designed to incorporate improvements introduced in newer Odoo versions while maintaining compatibility with legacy 10.0 installations that are no longer officially maintained.

Current functionality

  • Adds support for the BDNS convocation number field in the official 347 export file layout.
  • Updates the export configuration to comply with recent AEAT format requirements.

The module modifies the export configuration in a controlled way, without altering the original module source code.

Future roadmap

This module will progressively incorporate improvements and regulatory updates implemented in later Odoo versions, backported to version 10.0 when technically feasible.

The objective is to maintain a reliable and compliant Model 347 export for long-term Odoo 10.0 deployments.

Technical approach

  • Extends export configuration via XML inheritance.
  • Introduces new fields in the 347 report model.
  • Preserves backward compatibility.
