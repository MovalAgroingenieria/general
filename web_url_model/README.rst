=====================
URL Model Display
=====================

**Table of contents**

.. contents::
   :local:


Description
===========

This module adds the model name (res_model) as a query parameter in the browser
URL when navigating Odoo. For example: /odoo/action-735/1?res_model=res.partner

This makes it easier to identify which model you are viewing directly from the URL.
