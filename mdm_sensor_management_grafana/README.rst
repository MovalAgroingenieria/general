==================================================
Measurement Device management: Grafana Integration
==================================================

This module extends mdm_sensor_management by integrating comprehensive data
visualization through Grafana.

It enables interactive dashboards and real-time graphical analysis of sensor
readings, offering deeper insight into measurement trends and system performance.

By linking Odoo's structured sensor management with Grafana's powerful
visualization tools, this module provides a seamless environment for monitoring,
diagnostics, and decision-making.
