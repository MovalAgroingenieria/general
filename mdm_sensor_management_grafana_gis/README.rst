=============================================================
Measurement Device Management: Grafana-GIS Integration Bridge
=============================================================

This module creates a bridge between MDM sensor management GIS functionality
and Grafana visualization, enabling geospatial visualization of sensor data
through interactive Grafana dashboards.

It connects the geographic information system (GIS) features of MDM sensors
with Grafana's powerful graphing and visualization capabilities, allowing
users to view sensor locations on maps while analyzing their measurement
data in real-time charts.

The module serves as an integration layer that:

* Links GIS-enabled measurement devices with Grafana dashboards
* Provides geographic context to sensor readings visualization
* Enables spatial analysis of measurement data through Grafana
* Facilitates monitoring of distributed sensor networks with map overlays

By combining Odoo's GIS sensor management with Grafana's visualization engine,
this module delivers a complete solution for geographically-aware sensor
monitoring and analysis.
