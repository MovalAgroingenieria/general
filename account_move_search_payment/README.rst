===========================
Account Move Search Payment
===========================

Description
===========

This module improves the Account Move user experience by adding additional
search filters to easily distinguish between paid and not paid accounting
entries, including invoices.

It allows accountants to quickly filter account moves based on their payment
status directly from the search view.
