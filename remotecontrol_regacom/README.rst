==============================
Remote Control Engine: Regacom
==============================

Regacom integration module for water meter readings via SQL database connection.
Provides automatic synchronization of readings from Regacom database tables (historico_iru, CAUDALES, etc.)
into Odoo sensor readings.

Installation
============

No additional configuration required after installation.

Configuration
=============

Configuration details are available in the Remote Control help section within the application.
Navigate to: Remote Control > Remote Control > Regacom > Help tab for complete documentation
including connection parameters, device setup, sensor configuration examples, and table structures.
