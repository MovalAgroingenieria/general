======================
Partner Mobile Buttons
======================

Description
===========

This module adds subdivisions for 'mobile buttons' to form and kanban views of
partners. The button style attributes are changed to fit in these views.

Other modules can use the class 'mobile_buttons' or 'mobile_buttons_kanban' as
anchor to insert buttons there keeping the same style.
