Base Assembly is the core module for corporate assemblies in Odoo.

It provides the main business models and workflows for assemblies, agenda items, attendees, delegations, representations, and voting sessions. The module also includes operational actions, security rules, and reporting assets used by companion addons in the same ecosystem.
